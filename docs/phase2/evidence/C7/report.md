# C7 逐栋几何对照

`2059f70` 更新了 L1 建筑装饰条和入口雨棚的判断。关闭地标替换后，比伯里、北京 CBD、北京领秀三个样本的 888 栋建筑均通过 AC306 的逐栋阈值。

| 样本 | 栋数 | 优化后最大包围盒差 | 优化后最大三角形数相对差 |
| --- | ---: | ---: | ---: |
| 比伯里 | 148 | 1.156 cm | 0.495% |
| 北京 CBD | 477 | 3.191 cm | 0% |
| 北京领秀 | 263 | 1.852 cm | 0% |

真实样本中，`way/849169561` 的一段墙由一期的 1.997203 m 量化为 2.000771 m，跨过 2 m 墙顶装饰条阈值，使瓦片多出一个盒子。修复前比较为 172 对 184 个三角形，修复后均为 172 个。旧报告的雨棚偏差在本次基线已低于阈值，新增的合成用例构造了跨过 10 cm 平局阈值的两面墙，并检查带提示和旧格式的实际雨棚包围盒。

构建器比较源投影和瓦片网格的规则结果，在会翻转的建筑上写入规范化边长。运行时据此选择装饰条及雨棚，继续使用瓦片坐标生成几何。三组数据共 32 块含建筑的 L1 瓦片，2 块各有 1 栋携带提示。旧瓦片继续从轮廓计算。逐样本数据见 `buildings.json`。

```sh
npm run build:packages
node --test test/phase2-generators.test.js test/phase2-wall-lengths.test.js test/phase2-massing.test.js test/phase2-build-options.test.js
npm run test:types
```
