# 二期性能摘要

2026-11-26 在本机 Ryzen 7 7840S / Radeon 780M、Linux、Chrome 158、1280 × 720、DPR 1、balanced 实测。Android 和 iPhone 均未验证。一期 RTX 4090 的结果只覆盖一期场景包。

| 里程碑 | 使用的实测方法与结果 |
| --- | --- |
| M0 工具链 | 一期格式化前后 201 个 JS/TS 文件的转换结果一致。此阶段未引入瓦片渲染。见 [A 报告](A/report.md)。 |
| M1 瓦片 | 相同 167 块 L1 的 Node 解码和生成 p95 从 147.5 ms 降至 85.3 ms，目标 60 ms。京都 7 块在独立 Chrome Worker 的基准中从 228.1 ms 降至 165.1 ms。见 [C5 报告](C5/report.md)。 |
| M2 运行时 | 京都往返 20 次的驻留估算稳定在 13,473,148 B。GPU 拾取 p95 为 1.4 ms。见 [D2 实测](D2/report.md)。 |
| M3 整城 | 恩克赫伊曾真实 PBF 构建出 272 块瓦片。构建吞吐、内存、恢复和缝隙抽查见 [F 报告](F/report.md)。 |
| M4 风格 | 五次切换保持几何对象身份，新增网络请求 0。见 [D2 实测](D2/report.md)。 |
| M5 本机漫游 | 基线 601.2 秒、35,927 帧、首个可用画面 667 ms、首屏编码体积 790,518 B、瓦片错误 0。帧间隔 p95 16.7 ms，每分钟长帧 1.70 次。Worker p95 265.2 ms，单帧上传峰值 20 ms。见 [I 基准报告](I/report.md)。 |

基线为本轮开发期间的本机测量，同时有其他构建任务。报告逐份记录 SDK 提交和数据哈希。驻留字节为运行时估算，逐帧日志按 I 报告的命令写入仓库外。
