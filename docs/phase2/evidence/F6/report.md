# 多边形关系成员与河岸水域

2026-11-26，在 Linux、Node 24.18.0 上，以 `60cace3` 为基线复核。署名和输入文件 SHA-256 见[示例清单](../../../../examples/cities.json)。

## 输入与几何

`test/phase2-pbf.test.js` 的同源夹具包含带孔的 `waterway=riverbank` 关系。外环 way 带有 `natural=water`，内环是有独立 OSM 身份的建筑。分别读取 PBF、从全部节点/路径/关系还原的 JSON，得到同一块水面、一个孔和三栋建筑。外环不会作为另一块水面填孔。两种构建的全部瓦片和覆盖位图逐字节一致。另一个夹具核对公园外环所带的独立建筑或商业用地属性，以及公园本身的去重。原有的带内院建筑去重夹具继续通过。AC306 三个样本的逐栋比较增加了北京的 `way/233513061`，现有 889 栋，继续使用原包围盒与三角形阈值。

```sh
npm run build:packages
node --test test/osm.test.js test/phase2-pbf.test.js
```

Amsterdam Centrum 使用 [F 报告](../F/report.md) 的带日期 PBF 及独立 libosmium 建筑 JSON（SHA-256 `ac97d6d8c915fff843b733fb18b4c1945964378b9019ea1be9a1b8d5bab209c1`）分别重建。按该报告的 `compare-city-buildings.mjs` 命令检查，双方各有 5,278 个建筑身份，双向差集均为空。旧版双方各为 5,277 个。本次恢复的建筑为 `way/1320477256`，旧身份全部保留。

## 缓存升级

完成记录、PBF 磁盘要素索引、分格计划共同使用 `5-multipolygon-members` 构建缓存修订号。用同一二进制夹具及文件名分别在旧版本生成完整目录、在计划落盘后中断和在第一块瓦片编码后中断。用新版 `resume: true` 恢复三个目录，三次都重新读取 PBF，各自产物哈希均与新版空目录构建一致。直接比较新旧版空目录产物，可见三块瓦片发生变化。瓦片编解码格式保持兼容。
