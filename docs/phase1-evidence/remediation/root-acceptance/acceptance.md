## 边界与复现

性能通过只覆盖实际记录的桌面设备与指定案例；未验证 Linux/macOS/移动 GPU 或任意大城市无限覆盖。公共数据源不提供本项目的 SLA：默认 main/POST 的历史 502 仍真实，已验证的欧洲 GET 服务有地域边界；项目支持明确选择端点、自托管及缓存离线重建。

GLB携带可表达的几何和材质，网页的屏幕后处理不等于可移植GLB风格。包仍保留 private 标记；当前交付是本地集成分支上的代码与证据，不包含公开发布或远端部署。

归档后的参数26项、source锁9项、真实CLI只读文件审计、GPU完整性17项与12案raw重算、几何12个脚本已从最终目录实际复跑通过，路径迁移没有改变测试口径。几何wrapper以内容相同且可从集成分支克隆到的 e11990c 替代 donor Git 引用；原脚本/失败JSON保持原字节，临时派生记录可追溯。

具体可复跑命令见各归档目录 README。所有重跑输出写 ignored work，历史失败与通过 JSON 保持不变。最终生成场景、GLB、原始下载大数据、浏览器缓存不提交。
