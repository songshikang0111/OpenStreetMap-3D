# 远景立面分层 · v0.4.2

2026-10-30，基线 `74a5983`（v0.4.1）。范围：通用立面着色与漫画合成，保持本地国贸样本、现有几何及地标规则。

## 证据与诊断

本轮重新打开[原版北京 CBD](https://tools.oyasumi-gamedev.com/rokehan/#ll=39.909500%2C116.460500&s=1000&far=2&n=Beijing+CBD)，存档见 `evidence-distance/original`。01/02 是同机位开启/关闭 **Distant windows**；03 是更远广角，04 是街道俯视近景。原版明确描述该开关为保留远楼的小玻璃矩形。开启后能看到白墙冲孔、横带、深幕墙与竖缝；关闭后高楼趋向无窗的网点体块。截图和[作者说明](https://oyasumi-gamedev.com/tools/rokehan/)不能证明其私有着色器代码。

本地旧版：窗格约12.5→3.3像素时 `fade` 归零，连材质与反射信号一并消失；后处理 `smoothstep(.32,.82)` 再次压制衰减后的值。彩色分支保留平均覆盖，但漫画仅用中性光照与AO生成网点。同向受光的建筑因此同质化。用 `max(fwidth(u),fwidth(v))` 同时衰减两轴，还会错误抹掉掠角下仍清晰的楼层带。

## D1 · 按可见尺度保留建筑特征

- 同一布局的横、纵窗格各自解析过滤，低于像素时收敛为其真实平均覆盖；不让失效的横轴连带删除纵轴。
- 细窗墨线和远材质灰度分开：`color.a` 传可辨认建筑细节，现有 `light.a` 在程序立面上传远玻璃覆盖，在其他对象上仍传落影。
- 远处保留窗墙比例、宽反射、确定性玻璃明暗与开间组带；这些示意规则不代表实测立面。不随机重抽、不用坐标或相机预设识别建筑。
- 在细节淡出之前完成墨线映射，避免第二次阈值将淡出量整段抹掉；材质灰度只参与网点，不参与黑块/边缘检测。
- 降低立面中性光照底纹与细窗的叠加，地面落影逻辑保持独立。

## D2 · 回归与证据

- 本地新旧使用相同相机、FOV、种子、光照和画幅；包括俯瞰、天际线、中景、极远景、近景和彩色。
