# 桥头坡道与天桥楼梯：独立验收

2026-10-30。图审版本 **f7f05db / v0.4.1**，对照基线 **3a10c29 / v0.4**。

结论：**本轮可以交付。R4「道路与街道」建议由7.5提高到8.0/10**。这是沿用上一轮尺度的人工评分；本次不重评其他项目或总分。

## 独立几何证据

[独立测试](../test/road-grade-audit.test.js)采用另写的线性采样和凸多边形求交，未复用生产代码的交点、裁切或高度采样函数。

- 78个原始共享OSM节点，在重采样和合并后的路段上保持高度连续；道路输入数组反序后，全部节点高度不变。
- 184对真实跨越、5578个实际重叠顶点通过桥板底净空检查。最低机动车净空4.9739m，最低纯步行净空2.95m。
- 机动车最大坡度10%，自行车路径限制12%；四条三节点双翼楼梯正确在内部桥台处分为两段。
- 最终统计为28段楼梯、1054个踏步。推断树木2473→2400：34棵因坡道边缘位置移除，39棵因楼梯或桥面树冠冲突移除。数据见[统计记录](evidence-road-grades/stats.json)。

## 仍需保留的限制

1. 高程由OSM连接、相对层级及几何约束推断，没有实测地形。290条way调整高程，其中66条原本没有bridge标签的机动车道路局部抬升；路基、桥台土体、建筑入口与真实地势仍需后续处理。
2. 仍有23条非台阶步行路径超过12%坡度，最大35%。这是欠缺楼梯/高程标记时的示意连接，不是无障碍通道完成度。短连接835994223已从256.8%陡壁降至35%，代价是相邻两条住宅道路各约30m局部升高，不能据此宣称实景高程更准确。
3. 漫画模式中密集踏步与扶手会形成较重的黑块；匝道分叉、桥端路基和远处细栏杆仍可细化。最终约束闭包保证连续和坡度上限，但不代表所有纵断面都是严格C1曲线。

本次验收认可通用连接规则和可见故障修复，不增加地标、坐标或截图机位专用补丁。
