# v0.4 引擎细节打磨约定

日期：2026-10-30。基线为 f3a483e（v0.3），同一国贸 OSM 样本、相机与共有参数。继续使用 R1–R7 人工量表，不把功能完成度当作还原率。

| 需求 | 证据与问题 | 通用改动 | 验收 |
|---|---|---|---|
| P4 立面布局一致 | v0.3 的 shader 与实体细节分别计算 bay，部分窗台不对齐；普通建筑重复 | 共享墙面布局，按类型与稳定种子选择窗内分格、窗间墙与层间带 | 人工合成墙面检查几何/图案对齐；09近立面、03街道、10屋顶同机位对照；形体与OSM身份保持 |
| P5 玻璃层次 | 09近立面大片玻璃均匀发暗 | 所有玻璃家族使用连续的大尺度示意反射和留白，保留屏幕空间过滤 | 漫画、线稿、彩色近/远景检查；说明非真实环境反射或影像重建 |
| P6 树木连续细节 | 95米处近远树硬切，预算按输入顺序截取 | 保留基础冠体，叶簇与枝干随距离连续变化；稳定选择最近树、预算有界 | LOD边界、密集预算、回放测试；所有渲染通道共用几何；树位和数量不变 |
| P7 地面留白与投影 | 原版O04/O07有大片白地，v0.3街景地面同频灰网点过多 | 从已有灯光通道取得落影量，区分平地底色与落影/AO，复用原阴影贴图 | 03街道、11路口对照；开关阴影确实影响投影；标线白底、四模式不回归；不新增场景渲染遍次 |

每项完成独立 Git 提交。主代理检查截图与集成，独立研究代理审计原版差距；证据报告保留观察与推测的区别。若视觉验收未见收益，不因代码已写就加分。

本轮不扩展地图范围、不新增地标专用形体、不把程序门窗/植被/反射称为实测。近域高精度阴影、桥墩/地形、树叶图片替身和更完整建筑库仍需后续评估。
