# v0.4 独立视觉终审

日期：2026-10-30。对照基线为 v0.3（`f3a483e`），本轮实现截至 `ec70715`。本文件由独立对照子代理完成；前期差异研究继续保留在 [visual-gap-audit.md](visual-gap-audit.md)，不以完工结果改写当时的观察。

**建议接受本轮优化，人工加权评分从 68.50 提升至 71.75 / 100。**主要增益来自窗格与实体构件对齐、玻璃层次、桥底与支撑、路缘和铺装，以及地面留白与投影分离。树木 LOD 和几何预算改进不直接换算为静态画质加分。

## 复核范围与边界

- 查看了本轮 01–15 号最终画面，重点逐张对照 03/04 街道、09 立面、10 屋顶、11 路口及新增 12–15 道路细节。新增道路机位有同机位 v0.3 基线；证据保存在 [evidence-v04](report.html)。
- 额外检查了屋顶机位的 [投影开启](extra/shadow-on.png) / [投影关闭](extra/shadow-off.png)。同一机位的开关消融用于判断网点是否跟随投影，不能证明原版使用同一 shader 实现。
- 原版对照沿用 2026-10-29 的同地区存档，未实现与原版相机、太阳和地图快照的精确配准。分数是此前 R1–R7 人工工程量表的延续，不是现实还原率，也不是图像相似度百分比。
- 本审计负责视觉判断；自动测试、相机记录、逐张尺寸/加载帧检查和性能预算由主验收报告记录。静态截图不能单独证明整个相机运动过程无跳变，亦不能证明多设备帧率。

## 核心画面的终审结论

**建筑近镜通过。**[09 立面](after/09-facade.png)中实体窗台跟随窗格下沿，细黑边提供厚度；玻璃跨楼层的亮暗变化比逐格随机颜色更连贯。03/04 说明改善不只发生在一个机位。它们仍是示意立面与示意反射，没有恢复真实玻璃所反射的邻楼。

**地面留白与投影分离通过。**[11 路口](after/11-crossing.png)的白地、浅铺装和标线层次清楚；[10 屋顶](after/10-roof.png)中，投影使地面形成可辨形状。不能把改动概括成“所有地面都更白”：03 默认街道仍处于大面积阴影中，最终画面比旧版更暗；这是落影组织的变化。是否合适应看太阳和投影开关，而不是要求每张图统一提亮。

**桥梁结构和步道改善通过，接入关系仍不完整。**[12 斜看立交](after/12-bridge-oblique.png)、[13 桥下彩色](after/13-bridge-under.png)的前后对照，最显著变化是旧版近乎透明/无厚度的桥底变成有实体厚度与支撑的结构。[14 天桥](after/14-footbridge.png)补齐可读护栏；[15 人行道](after/15-sidewalk.png)的路缘开口和砖缝能提供近处尺度。不能把“路缘开口”写成已做坡道，也不能把新增支撑写成真实桥墩测绘。

**树木形体回退已补正，静态质量保持。**中途 09 右下树曾过度趋近单个梨形冠，最终重拍恢复外围叶簇。最终 03/04/09/11 没有继续表现出该局部回退；但球簇和重复明暗仍明显。本轮可以交付更稳的生成与层级控制，不宜声称树叶画法已经明显接近原版。

## 阻塞项与保留问题

终审曾发现 03/05/07/08/11 被保存为加载画面，已要求重新拍摄。主代理改为导航与截图分开的两步流程后，本审计逐一重看了这五张，以及 04；最终均可见已构建场景与正常统计，**该证据阻塞已解除**。

当前所复核画面没有发现需要阻止本轮交付的新视觉回退。以下问题仍限制质量与后续扩展，不能因本轮通过而视作完成：

- 构建记录仍报告 **78 处名义高度跳变**。桥板、栏杆、支撑让结构更可读，未解决整张路网的三维衔接。
- 天桥楼梯和无障碍坡化未实现；过街口只裁开路缘。可看见桥不等于行人可合理到达桥上。
- 近树的整冠明暗与叶缘疏密不足，中远树种轮廓仍有限。
- 高楼细肋在部分距离和方向上仍出现断续线，默认路口与天桥视角可直接看到。
- 屋顶/首层用途语法、近处接触阴影精度、真实道路高程与远景环境仍有差距。现有彩色偏柔和是风格选择，不单独扣作缺陷。

## 后续最值得做的三项

1. **道路高程连接和行人接入。**先统一相连路段的高度约束，补桥头过渡；再按数据或明确推断规则补楼梯、坡道及过街高差处理。至少用桥下、桥头侧面和顶视三种证据验收，避免只在俯瞰成立。
2. **树冠整体明暗与细叶缘分工。**整冠定大暗面，叶簇定轮廓，细叶纹理只在足够屏幕尺寸出现。优先重组视觉层次，不继续无条件加面数；彩色、线稿、漫画必须一起复核。
3. **按屏幕尺寸稳定建筑细线。**对窗框、竖肋、接缝分角色，削减不可辨的内部线而保留楼体外轮廓与转角；用连续相机运动和双倍导出检查，不能只挑一个静态机位。

本轮的提升是通用生成/渲染规则在现有国贸数据上的改善。它不改变此前结论：特殊地标有专用形体规则，普通细节和补植包含推断；尚不应由这组样本的评分推导出“全北京已可自动达到同等细节与正确性”。
