# v0.4.1 道路纵断面与天桥连接

2026-10-30，用户截图指出机动车立交桥头断层、天桥上下通道悬空。基线为3a10c29，保留同一份国贸数据。

1. 沿OSM共享节点连接道路；解析裁边段时保留真实node ID映射，不把仅平面相交的道路接到一起。
2. 桥头与分层匝道通过相连路网生成连续纵断面。近桥分叉参与分摊高差；机动车最大示意坡度10%，实际跨越按路宽和桥板底净空验收。
3. 路面、标线、护栏、桥板、桥墩净空使用同一高程。路边设施贴合坡道；悬空边铺上的推断街树移除并计数。
4. 已标注highway=steps的路线生成踏步、踢面、平台、侧底及扶手；在内部共享节点拆出两翼楼梯。没有楼梯标签的步道不得伪称实测楼梯。
5. 保存桥头、天桥、楼梯近景和立交4组同机位前后截图；独立检查全样本共享节点、最大坡度、跨越净空和双翼楼梯。每项完成Git提交。

高程仍以layer推断为起点，使用连接、坡度、相对净空约束调整，非测绘值；没有地形/河床/工程设计参数。10%和4.8m用于此原型的几何约束与防回退，不是道路规范声明。缺乏步骤标签的陡步道、建筑入口连接及无障碍坡道仍需另行审查。
