# 远景立面专项独立验收 — v0.4.2

日期：2026-10-30。评审：独立子代理 `distance_facade_review`。评审代理未参与源码修改；先审查基线和原版证据，再对迭代截图提出反馈，最后检查全部五组最终截图。

**结论：本轮“建筑拉远后不再全部退化为同一种网点”的专项静态验收通过。** 中景与天际线已经能读出横向带窗、竖向分组幕墙和较浅墙面的区别；更远时保留平均材质深浅；近景窗格与实体窗框仍可辨认。这个结论不等于达到原版的视觉层次，也不代表所有距离无噪声、连续移动无闪烁。

## 原版观察与推断边界

本次复核了原始归档的 `01-overview-ink.jpg`、`02-wide-ink.jpg`、`10-landmark-wide-20mm.jpg`，并复核了本轮新增的 [远景窗开启](evidence-distance/original/01-overview-on.png)、[远景窗关闭](evidence-distance/original/02-overview-off.png)、[广角开启](evidence-distance/original/03-wide-on.png)。

可以直接观察到：原版广角中仍有白墙冲孔窗、浅色横带、深色幕墙和白竖缝；不同立面有明显的整面明暗差。关闭 **Distant windows** 后，中后排建筑的窗线和材质差异明显减弱，前景部分建筑仍保留细节。极远背景也会淡化、简化。

这支持“原版有近远立面的不同表现，远景窗选项影响建筑可读性”的判断，**不能仅据截图断言它采用了哪一段 shader、哪个像素阈值或与本项目相同的通道编码**。本次多尺度材质分离是我们自己的实现方案。

## 源码复核

基线的细窗信号整体乘距离衰减，随后又经历漫画分支的阈值；彩色分支保留的平均玻璃覆盖没有传入漫画材质表达。结果是远景建筑主要剩下中性光照与 AO，出现相似网点。

最终版本可直接在源码确认以下变化：

1. [facade-shader.js](../src/facade-shader.js) 分别输出可辨认细节和低频材质覆盖；`inkTone` 使用平均覆盖 `meanU * meanV`，不再携带细窗 `mask`。
2. 两个轴分别根据投影足迹过滤。横向被透视压缩时，不强制同时删除仍可辨认的楼层方向信息。
3. 玻璃与横带类使用不同方向的分组，分组来自稳定的布局参数；不是按照指定楼栋坐标更换纹理。
4. 宽分组也按实际网点尺寸过滤，接近 2–4 个网点单元时逐渐退到平均材质，减少组带与网点互相调制的块纹。
5. [ink-renderer.js](../src/ink-renderer.js) 按对象类别消费低频材质通道，地面仍使用自己的投射阴影信号。
6. [facade-loft.js](../src/facade-loft.js) 使用共享参考环周长，避免逐层重算开间数引起纹理横向漂移。它是通用放样函数，没有本轮新增的地理坐标补丁。[跨层测试](../test/facade-loft.test.js) 检查收缩、扩张后的物理接缝和立面坐标一致。

现有 [测试记录](evidence-distance/tests.txt) 报告 70 项通过。评审代理阅读了记录和相关测试，本报告不将单元测试通过解释成视觉运动已经验收。

## 保留问题与下一步验收边界

- **仍有细碎纹理。** 01 的前侧板楼、03 的右下板楼是更敏感的后续测试区域。最后一轮过滤已有改善，但不能写成“已消除所有摩尔纹”。静态图中的颗粒或块纹也不能直接证明运动时一定闪烁。
- **原版的整面层次更清楚。** 原版常能读出深黑整面、连续白缝、浅横带和留白；本地部分楼仍更多依赖网点浓度变化。继续优化时应优先整理这些尺度关系，而非继续增加窗格数量。
- **极远简化应被允许。** 04 中的楼宽已经很小，保留平均材质、轮廓和立面转折比保留每条窗带更重要。各楼不再同灰不等于每栋都需要独一无二的花纹。
- **近景宽亮带可以更贴合布局。** 09 中局部亮带穿过窗面，使可见窗面宽度变化；可在以后让宽分组边界更好地对齐已有开间。当前未见窗框或近景结构大面积丢失。
- **连续缩放、平移、旋转尚未通过录屏验收。** 本报告没有运动证据，不能确认阈值过渡是否完全无闪烁；后续应包含掠角墙面和临界投影尺寸。
- **不扩大结论范围。** 未在本次独立评审中验证高倍导出、所有网点滑杆值、不同设备像素比和大范围城市性能；也未重新验收桥梁与道路。
