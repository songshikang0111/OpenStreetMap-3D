# v0.4 引擎与道路打磨验收

2026-10-30。在同一国贸样本完成第三轮，人工工程量表 **68.5 → 71.75 / 100**。见 [15组滑动对照](evidence-v04/report.html)、[独立原版差异审计](visual-gap-audit-v04.md)及[最终图审](visual-gap-v04-validation.md)。分数不是实景还原率；原版存档为同地段、不同机位参考。

## 本轮结果

- 共享布局同时驱动程序窗格、实体窗台和分格。四类建筑各有三种稳定语法；未修改OSM轮廓或地标形体。修复旧版按输入顺序截断近窗记录的问题，改为按附近墙段生成，实例上限18000。正式立面机位实体框0→5718，街道0→3878。
- 玻璃增加连续的方向性示意亮区，滑杆默认65%，保存/重载100%已验证。它不是实际邻楼或卫星图反射。
- 中性光照通道的alpha记录落影，明亮地面保留白纸、落影与接触处上网点。默认街道在楼影中，网点变深；不能称所有地面都更白。
- 树冠保留共同基础冠与18个外围叶簇，几何随距离连续变化，所有渲染通道共用。不增加树位；修复中段过渡叶簇埋入基础冠的回退。树冠硬上限约133.99万→99.81万三角形，静态视觉评分保持6.5。
- 普通人行面抬高到0.47m，车道/明确过街面0.32m；近处铺装接缝按像素过滤，材质分类与沥青分开。桥上或禁步行道路不机械增加边铺，推断边铺裁开建筑。149段路缘为横道裁出开口；斑马线贴近路面，不再像厚铺砖。
- 桥面补侧底厚度、护栏和避障桥墩，保留同层桥路分支开口。样本生成232根支撑、3001段护栏，约110156个结构三角形、3个合并网格。74个不安全支撑候选跳过，不把它们强行放进下层道路。

## 验收与证据

49项完整测试通过，最后斑马线厚度修正另复跑8项街道测试；生产构建通过。道路平面38884对候选面的独立重叠检查通过；实际桥墩逐一检查下层道路净空。树木测试包含近/远及96棵预算边界、相机移动、种子/平移/输入顺序，另用真实网格投影检查中段叶簇确实露出基础冠。

15组1920×945版本截图，共30张。原11组复用已归档v0.3基线，新增桥下、立交俯视、天桥和路缘4组两版同拍。逐项核对机位、画幅与共有参数；重新拍摄早期加载帧，检查全部图像非空与联系表。漫画、线稿、彩色、白模、阴影开关和PNG导出另留证据。本轮没有重新验证GLB外部导入。

几何预算见 `evidence-v04/geometry-budget.json`，可运行 `node scripts/measure-v04.mjs` 从Git基线f3a483e重建。该数值是视锥裁剪前、单场景遍次，不是GPU帧率。新布局属性与桥结构增加几何内存，整场景属性约36.6MB→56.4MB；树木降面数不等于所有机位都更快。

## 尚未解决

桥高仍按layer×7m推断，存在78处名义高度不一致连接点。桥头坡道、天桥楼梯/上下通道、过街缓坡没有完成；路缘开口不等于无障碍坡道。近处阴影、整冠黑白分组、细叶疏密、远景竖肋断续、临街入口/共墙、屋顶用途化和地形仍是后续重点。

本轮主体均为通用生成和渲染规则，没有增加机位判断、国贸坐标补丁或新的地标专用建模。地图范围保持原样。
