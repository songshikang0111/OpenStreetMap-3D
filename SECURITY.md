# Reporting a security issue

For a suspected vulnerability in the local server, CLI, tile decoder or SDK, contact a maintainer privately. Use **Security → Report a vulnerability** on the GitHub repository when available. If that option is unavailable, use the maintainer's published contact information, or request a private reporting channel in a public issue without including sensitive details.

Include the affected version or commit, component, impact and a minimal description of the conditions that trigger the issue. Remove credentials, personally identifying information and private source data. Maintainers can then arrange a private exchange of any additional material and coordinate a fix.
